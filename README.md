# 📦 Inventory Management System

An Inventory Management System built using **ASP.NET Core MVC**, **C#**, **Entity Framework Core**, and **SQL Server**. This project helps manage products, categories, and inventory with a clean and user-friendly interface.

---

## 🚀 Features

- ✅ Add Product
- ✅ View Product List
- ✅ Edit Product
- ✅ Delete Product
- ✅ Dashboard
- ✅ SQL Server Database Integration
- ✅ Entity Framework Core
- ✅ Responsive UI
- 🔄 More features coming soon...

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/MaYaNk03mkm/InventoryManagementSystem.git
```

2. Open the project in Visual Studio.

3. Update the SQL Server connection string in `appsettings.json`.

4. Apply database migrations.

```bash
Update-Database
```

5. Run the project.
